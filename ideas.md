### Ideia 1: Minimalismo Corporativo com Tipografia Hierárquica

**Design Movement:** Bauhaus contemporâneo com influência suíça

**Core Principles:**
- Máxima clareza através de hierarquia tipográfica rigorosa
- Espaço negativo como ferramenta de elegância
- Contraste funcional entre elementos
- Estrutura geométrica invisível (grid 12 colunas)

**Color Philosophy:**
- Fundo: Preto profundo (#0a0a0a) para transmitir solidez e profissionalismo
- Texto principal: Branco puro (#ffffff) para máximo contraste e legibilidade
- Destaque: Cinza claro (#d0d0d0) para elementos secundários
- Acento: Azul-cinzento discreto (#6b8fa3) para CTAs e destaques funcionais
- Raciocínio: Paleta monocromática com um único acento cria sofisticação sem ruído visual

**Layout Paradigm:**
- Seções full-width com padding assimétrico (espaço maior no topo)
- Cards com bordas sutis em vez de sombras
- Alinhamento left-aligned para texto (mais técnico que centered)
- Espaçamento vertical generoso entre seções (120px+)

**Signature Elements:**
1. Linhas horizontais finas como divisores (1px, cinza escuro)
2. Tipografia em duas escalas: títulos em 48-56px, corpo em 16px
3. Ícones minimalistas em estilo line-art (2px stroke)

**Interaction Philosophy:**
- Transições suaves e lentas (300ms) para sensação de controle
- Hover: mudança de cor do texto (branco → cinza claro)
- Sem animações excessivas; movimento é funcional

**Animation:**
- Fade-in ao scroll (opacity 0 → 1, 400ms ease-out)
- Hover em links: underline que cresce da esquerda para direita (200ms)
- Botões: mudança de cor de fundo suave (100ms)

**Typography System:**
- Display: Poppins Bold 700 (48-56px) para títulos principais
- Heading: Poppins SemiBold 600 (32-40px) para seções
- Body: Inter Regular 400 (16px) para texto principal
- Small: Inter Regular 400 (14px) para descrições
- Espaçamento de linha: 1.6 para corpo, 1.2 para títulos

### Ideia 2: Técnico Moderno com Destaque Azul Discreto

**Design Movement:** Design de sistemas (System Design) com toque de tech-forward

**Core Principles:**
- Funcionalidade acima de ornamentação
- Paleta reduzida com um único acento que guia atenção
- Tipografia técnica mas legível
- Estrutura modular e escalável

**Color Philosophy:**
- Fundo: Cinza muito escuro (#1a1a1a) para reduzir fadiga ocular
- Texto: Branco (#ffffff) com cinza-claro (#e0e0e0) para secundário
- Destaque: Azul-petróleo (#4a7c9e) para CTAs, links e destaques
- Acento secundário: Cinza-médio (#505050) para separadores
- Raciocínio: Azul discreto transmite tecnologia sem ser agressivo; cinza escuro é mais confortável que preto puro

**Layout Paradigm:**
- Seções com largura máxima de 1200px, centralizadas
- Cards com background ligeiramente mais claro (#252525) e bordas finas
- Uso de colunas assimétricas (60/40 ou 70/30) para dinamismo
- Padding vertical de 80-100px

**Signature Elements:**
1. Pequenos ícones em azul-petróleo ao lado de títulos
2. Bordas esquerda em azul em cards importantes
3. Tipografia em duas famílias: títulos em Montserrat, corpo em Roboto

**Interaction Philosophy:**
- Movimento sutil e propositivo
- Hover em elementos: fundo muda para #252525 com texto em azul
- Botões com background azul, hover com saturação aumentada

**Animation:**
- Slide-up ao scroll (transform: translateY(20px) → 0, 500ms ease-out)
- Hover em cards: sombra sutil aparece (0 4px 12px rgba(74, 124, 158, 0.1))
- Botões: pulse suave no hover (scale 1 → 1.02)

**Typography System:**
- Display: Montserrat Bold 700 (52px) para hero
- Heading: Montserrat SemiBold 600 (36px) para seções
- Body: Roboto Regular 400 (16px) para texto principal
- Small: Roboto Regular 400 (14px) para descrições
- Espaçamento de linha: 1.7 para corpo, 1.3 para títulos

### Ideia 3: Minimalismo Escandinavo com Tipografia Geométrica

**Design Movement:** Escandinavo moderno com influência de design nórdico

**Core Principles:**
- Simplicidade radical: apenas o essencial
- Tipografia geométrica como protagonista
- Espaço branco abundante
- Foco em legibilidade e clareza

**Color Philosophy:**
- Fundo: Preto (#000000) para máximo contraste
- Texto: Branco (#ffffff) para clareza absoluta
- Destaque: Cinza-claro (#c0c0c0) para elementos secundários
- Acento: Azul-gelo (#5a9fb5) para interações e CTAs
- Raciocínio: Paleta ultra-reduzida transmite confiança através da simplicidade; azul-gelo é moderno mas não distrativo

**Layout Paradigm:**
- Seções com espaçamento vertical extremo (150px+)
- Uso de whitespace como elemento de design
- Alinhamento left-aligned com margens generosas
- Cards praticamente invisíveis (apenas separação por espaço)

**Signature Elements:**
1. Tipografia em escala extrema (títulos 60px+, corpo 16px)
2. Linhas horizontais muito finas (#2a2a2a) como separadores
3. Ícones geométricos simples em cinza-claro

**Interaction Philosophy:**
- Transições muito lentas (400ms+) para sensação de luxo
- Hover: mudança sutil de cor (branco → cinza-claro)
- Sem sombras; apenas mudanças de cor e opacidade

**Animation:**
- Fade-in lento ao scroll (opacity 0 → 1, 600ms ease-out)
- Hover em links: cor muda com transição suave (300ms)
- Botões: background muda de cinza para azul-gelo (200ms)

**Typography System:**
- Display: Space Grotesk Bold 700 (60-72px) para hero
- Heading: Space Grotesk SemiBold 600 (40-48px) para seções
- Body: Inter Regular 400 (16px) para texto principal
- Small: Inter Regular 400 (14px) para descrições
- Espaçamento de linha: 1.8 para corpo, 1.1 para títulos

## Decisão Final

Após análise das três abordagens, **escolho a Ideia 1: Minimalismo Corporativo com Tipografia Hierárquica**.

**Justificativa:**
- Bauhaus suíço transmite profissionalismo e método (alinhado com Core & Patch)
- Hierarquia tipográfica rigorosa comunica clareza sem jargões
- Paleta monocromática com acento azul-cinzento é técnica mas não agressiva
- Espaço negativo generoso reforça a ideia de "estrutura bem feita"
- Linhas finas e alinhamento left-aligned criam sensação de organização
- Escalável e sustentável para manutenção futura

**Aplicação:**
- Tipografia: Poppins para títulos (peso, hierarquia), Inter para corpo (legibilidade)
- Cores: Preto profundo (#0a0a0a), branco (#ffffff), cinza claro (#d0d0d0), azul-cinzento (#6b8fa3)
- Espaçamento: Vertical generoso (120px+), padding assimétrico
- Elementos: Linhas finas, ícones line-art, cards com bordas sutis
- Animações: Fade-in ao scroll, underline em links, transições suaves
